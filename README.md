# Portal Web para gestión de citas
Desarrollo de aplicacón para administrar las citas agendadas en una estética unisex
El portal web está desarrollada en Python con DJango y MySQL para el manejo de datos

# Clonar el repositorio
Puede clonar el repositorio introduciendo el siguiente comando de git en una terminal:

`git clone https://github.com/FabrixBq/CitasEstetica.git`

# Iniciar el servidor
Para iniciar el servidor es necesario navegar hasta la carpeta que contiene el archivo
manage.py (../CitasEstetica/Estetica/estetica) y después escribir el siguiente comando:

`python manage.py runserver`
